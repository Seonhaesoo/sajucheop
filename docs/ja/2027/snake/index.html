よくある質問

2027年の巳年（みどし）の運勢は何点ですか？

100点満点で87点、「恵まれた年」です。巳年（みどし）の支（巳）と年の支・未との関係（方合）、そして火の気が丁火・未土の年とどう出会うかで採点しています。韓国語版・英語版と同じ数字です。

2027年、巳年生まれの運勢は良いですか？

順風で、十二年の中でも温かい年の一つです。巳・午・未は夏の方合を作り、未の年はあなたと同じ方向へ進み、年の火は自分の五行と重なります。評価、誘い、注目がいつもより届きやすい年。代償は熱で、短気と、真夏に早く決めすぎる癖です。

2027年、巳年生まれにとって夏の方合とは何ですか？

十二支は季節ごとに三つずつ四組に分かれます。巳・午・未は南方・夏の組で、未の年にはあなたの季節が完成し、持ち味が抑えられるのではなく増幅されます。実際には温かさと可視性として現れ、唯一の注意はその同じ熱の取りすぎです。
