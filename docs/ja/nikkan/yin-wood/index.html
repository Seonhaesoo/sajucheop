乙

乙（きのと）・陰の木 —
草花

柔軟直感温かさ粘り強さ

サジュチョプ · 風に乗る草花

折れるのではなく、回り込む人。

あなたという人

突撃するのではなく、しみ込んでいく人です。場の空気や人の気持ちをすばやく読み、折れる代わりにしなり、気がつけば望んだ場所にちゃんと立っています。草花を弱いと言う人は、つたが崖を登りきる姿を見たことがないのでしょう。あなたの柔らかさは戦略であり、それはきちんと機能しています。

強み

  • どこでも生きていける適応力——新しい職場、新しい街、新しい人の輪にも、人の半分の時間でなじみます。
  • 人が口に出す前の気持ちをとらえる、細やかなアンテナ。

気をつけたいこと

  • 「いいえ」と言うのが苦手で、引き受けた覚えのない損まで背負ってしまいます。
  • 寄りかかる先ばかり探していると、自分自身の力が育つのが遅れます。

恋愛

相手にゆっくりと、そして完全に絡みついていきます。いちど絡んだら、手放すのは根ごと引き抜くようなもの——草花の別れが長く痛むのはそのためです。登れるほどしっかりしていて、登られていることに気づかないふりをしてくれるほど優しい人と、いちばんよく花開きます。

仕事

人間関係とタイミングで成り立つ仕事——営業、交渉や外交、ケア、デザインなど、人を読む力がそのまま技能になる分野です。よいチームの中、あるいは強いパートナーの隣で、いちばん高くまで伸びます。

相性 — 干合する相手、冲する相手

干合：庚（かのえ）・陽の金 — 鉄剣。 陰の木は陽の金と干合します（乙庚の干合）。つたが支柱を見つけたようなもの——登っていける頑丈な相手で、ふたり一緒なら、ひとりでは届かない高さまで行けます。

冲：辛（かのと）・陰の金 — 宝石。 陰の木は陰の金と冲の関係にあります（乙辛の冲）。宝石の鋭い縁は、草花を簡単に傷つけます。少し距離を置くことで、どちらも品よくいられます。

日干どうしの相性は入口にすぎません。二人の生年月日を入れると、相性診断が通変星（互いにとって何にあたるか）と五行の補い合いまで読みます。

身強・中和・身弱

同じ日干でも、ほかの七文字にどれだけ支えられているかで読み方が変わります。

  • 身強 — 真夏の草花です——四方八方へ一度に広がります。登る壁は十ではなく、二つに絞ってください。
  • 中和 — 柔らかいところは柔らかく、肝心なところにはしっかり根を張る——いちばん暮らしやすい草花の姿です。
  • 身弱 — 日陰の若芽です。まず登る壁を見つけてください。登ること自体は、あとから自然についてきます。
