      받은 파일, 내 캘린더에 어떻게 넣나요?

      인스타·카톡에서 열었다면 — 앱 안 브라우저는 저장이 막혀 있어요. 오른쪽 위 ⋯ 메뉴 → 외부 브라우저로 열기(사파리/크롬) 후 다시 눌러주세요.

      안드로이드 — 버튼을 누르면 파일이 받아집니다. 화면 위 다운로드 알림(또는 파일 앱의 Download 폴더)에서 사주첩-운세캘린더.ics를 누르면 캘린더가 열리면서 일정이 추가돼요.

      아이폰 — 버튼을 누르면 파일이 받아져요. 사파리 주소창 옆 ↓ 아이콘(또는 파일 앱)에서 파일을 열고 "모두 추가"를 누르면 캘린더에 들어갑니다.

      캘린더가 아닌 다른 앱으로 열려요 — 받은 파일을 길게 눌러 다른 앱으로 열기 → 캘린더를 고르세요. .ics 기본 앱은 휴대폰 설정에서만 바꿀 수 있어요. 날짜 한두 개만 넣을 땐 위 달력에서 날을 누르면 나오는 + 구글 캘린더에 저장 버튼이 앱 선택 없이 바로 들어가 가장 빨라요.

      PC · 구글 캘린더 — calendar.google.com → 오른쪽 위 톱니바퀴(설정) → 가져오기 및 내보내기 → 받은 파일 선택 → 가져오기.

      PC · 아웃룩 — 받은 파일을 더블클릭하면 일정으로 추가돼요.
