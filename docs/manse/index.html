만세력 — 일진 달력

날짜마다 일진(60갑자)과 음력, 절기가 드는 시각, 손없는날까지. 날짜를 누르면 그날의 년주·월주·일주가 열립니다. 글로 읽고 싶다면 날짜별 일진 페이지, 이사 날을 잡는다면 월별 손없는날, 달이 바뀌는 시각은 24절기 시각표에서.

손손없는날 절기
내 사주로 보는 좋은 날 찾기
일진이란

갑자(甲子)부터 계해(癸亥)까지 60개의 간지가 하루에 하나씩 끝없이 순환합니다. 오늘의 간지를 일진(日辰)이라 하며, 태어난 날의 일진이 곧 사주의 중심인 일주(日柱)가 됩니다. 이 만세력은 절기가 바뀌는 시각까지 계산해 년주와 월주를 세우는 정밀 방식입니다.
