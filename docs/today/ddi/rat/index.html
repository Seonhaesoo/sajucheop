오늘의 유(酉)는 쥐띠와 파(破)의 자리입니다. 잘 가던 일이 마무리에서 틀어지기 쉬우니 확인을 한 번 더 하세요.

재물

재물의 날입니다. 수금·정산·거래·투자 판단에 기운이 실리고 뜻밖의 수입도 기대해 볼 만합니다.

애정

약속이 어긋나기 쉬운 날. 미리 확인 연락을 해 두세요. 쥐띠는 좋아하면 챙기는 게 많아지고, 서운하면 말이 줄어듭니다.

일·공부

일을 벌이면 결실이 따르는 날. 다만 여러 일을 동시에 잡으면 흩어집니다.

건강
