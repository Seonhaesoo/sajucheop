# 사주첩 四柱帖

여덟 글자에 담긴 당신의 이야기 — 절기 시각 기준 정밀 만세력 기반의 무료 사주풀이 웹사이트.

**사이트**: https://sajucheop.com

첩(帖)은 시첩·서첩·화첩처럼 글과 그림을 모아 묶던 책. 사주첩은 당신의 명식과 매일의 운세를 한 장씩 담아가는 곳입니다.

## 특징

- **정밀 만세력 엔진** — 절기를 표가 아닌 태양 시황경 천문 계산으로 판정 (입춘 기준 년주, 절기 시각 기준 월주, 경계 ±2시간 경고). 진태양시 보정, 야자시, 1954~61년 표준시 변경 반영. 순수 JavaScript, 서버·외부 API 없음.
- **사주풀이** — 명식(십성·지장간), 오행 균형, 일간·십성 풀이, 신강약 판정
- **대운 그래프** — 10년 주기 흐름을 곡선으로 시각화
- **오늘의 운세** — 오늘 일진과 내 일간·일지의 관계(십성·합충)로 매일 갱신, 시간대별 흐름 포함
- **운세 캘린더** — 내 사주 기준 길일·충 주의일 월 캘린더 + 목적별 택일 + `.ics` 캘린더 내보내기
- **사주 캐릭터** — 10일간 유형 시스템과 인스타 스토리용 사주 명함 이미지 생성
